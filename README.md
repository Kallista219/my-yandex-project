# Музыкальный MP3-плеер «Lyceum Beats»

**Автор проекта:** Хиценко Анастасия  
**Учебное заведение:** Яндекс.Лицей  
**Технологии:** Python, PyQt5, SQLite, CSV/TXT  

---

## 1. О чём этот проект?
Я создала десктопное приложение — музыкальный MP3-плеер, который позволяет удобно слушать музыку, наводить порядок в своей фонотеке, распределять треки по плейлистам, добавлять песни в избранное и смотреть статистику прослушиваний. 

Программа разработана с красивым и минималистичным интерфейсом, поддерживает две темы оформления (Тёмную и Светлую) и полностью готова к работе на любом компьютере.

---

## 2. Главные функции приложения
- **Воспроизведение музыки:** Можно открывать аудиофайлы (`.mp3`, `.wav`, `.ogg`), управлять воспроизведением (играть, ставить на паузу, переключать треки назад и вперёд, включать повтор трека).
- **Интерактивная шкала времени:** Песню можно мотать кликом мышки в абсолютно любой момент шкалы (`ClickableSlider`).
- **Работа с плейлистами:** Пользователь может создавать собственные плейлисты, добавлять к ним описание, редактировать, удалять и переключаться между ними.
- **Избранное и поиск:** Понравившиеся треки можно отмечать звёздочкой (`★`), фильтровать список только по избранным, а строка поиска позволяет мгновенно находить песню по названию или имени исполнителя.
- **Аналитика и статистика:** В отдельном окне показывается общее число треков, количество прослушиваний на `QLCDNumber`, доля избранных треков на `QProgressBar` и топ-5 самых популярных песен. Отчёт можно сохранить в текстовый файл (`.txt`).
- **Импорт и экспорт:** Свои плейлисты можно выгружать в таблицы (`.csv`) и загружать обратно.
- **Смена тем:** Через меню или выпадающий список можно в один клик переключаться между Тёмной и Светлой темой (все цвета интерфейса и текста автоматически меняются и сохраняются в БД).
- **Динамическая обложка и окно «О программе»:** Для каждого трека автоматически рисуется виниловая пластинка с названием песни с помощью `QPainter`, а во вкладке «Файл» добавлено фирменное окошко с информацией об авторе проекта.

## 3. Из каких частей состоит код (Архитектура)
Проект написан на языке Python с использованием библиотеки графического интерфейса **PyQt5** и разделен на логические классы:
1. **Главное окно (`Mp3PlayerMainWindow`):** Основной экран программы со списком треков, поиском, фильтрами, кнопками управления плеером и панелью громкости.
2. **Кликабельный слайдер (`ClickableSlider`):** Наследник `QSlider`, позволяющий перематывать трек одиночным кликом в любую точку шкалы.
3. **Менеджер базы данных (`DatabaseManager`):** Отвечает за всю работу с базой данных SQLite (`music_library.sqlite`). В базе созданы **3 связанные таблицы**:
   * `playlists` — хранит плейлисты (`id`, `name`, `description`, `created_at`).
   * `tracks` — хранит треки (`id`, `title`, `artist`, `genre`, `file_path`, `playlist_id`, `is_favorite`, `play_count`) с привязкой к плейлистам через внешний ключ (`FOREIGN KEY`).
   * `app_settings` — сохраняет выбранную тему оформления и уровень громкости между запусками программы.
4. **Дополнительные окна-диалоги (`QDialog`):**
   * Окно редактирования трека (`TrackEditorDialog`).
   * Окно управления плейлистами (`PlaylistManagerDialog`).
   * Окно статистики (`StatisticsDialog`).
   * Окно «О программе» (`AboutDialog`).

## 4. Как запустить проект
1. Убедитесь, что у вас установлен **Python 3.8+**.
2. Установите необходимые библиотеки через терминал:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите главный файл приложения:
   ```bash
   python main.py
   ```
